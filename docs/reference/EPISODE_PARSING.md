# 集数解析规则

`app/episode.py` 是 FeedDock 集数解析的唯一实现位置。它不依赖数据库、网络或 FastAPI，因此预览、RSS 刷新和重试流程会得到同一套结果。

## 解析顺序

1. 若订阅配置了自定义正则，先按 `episode_group` 读取匹配组；
2. 选定分组不存在时，回退到第一个捕获组；没有捕获组时使用完整匹配；
3. 自定义正则未匹配时，依次尝试内置的 `EP12`、`- 12`、`[12]` 格式；无效的自定义正则直接返回空字符串，以避免配置错误意外匹配下载；
4. 未能识别时返回空字符串。预览页面会用第 1 集展示命名效果，但真实下载不会把它当作识别结果。

## 规范化与偏移

数值集数会去掉无意义的前导零和尾随零，例如 `003` 变为 `3`、`13.50` 变为 `13.5`。集数偏移只作用于可解析的十进制数；`special` 一类文本保持不变。

## 维护约束

内置模式按歧义度排序，显式集数标记优先于标题中的连字符和方括号数字。调整模式或回退顺序时，必须同步扩展 `tests/test_rss_service.py`，覆盖自定义正则、无效正则、分组回退和小数集数。
