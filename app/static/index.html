系统日志与调试

INFO 模式记录正常流程和错误；DEBUG 模式额外记录每个 API 请求、耗时和处理阶段。

500 错误会返回日志编号。可在筛选框中查看 ERROR，展开“详细内容”读取异常类型、处理上下文和完整 traceback。日志文件保存在 /data/logs/feeddock.log。
