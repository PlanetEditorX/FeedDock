qBittorrent 下载器

正在读取下载器配置…

qBittorrent 与 FeedDock 必须访问同一个宿主机媒体目录，但容器内路径可以不同。qBittorrent 保存根目录在这里配置；FeedDock 自己看到的路径在“刮削设置”中配置。

刮削设置

同步外部元数据，并在下载完成后写入 NFO、海报和背景图。

下载完成后自动刮削会先同步标题、评分、简介、海报和总集数，再在媒体目录写入 tvshow.nfo、season.nfo、剧集同名 NFO、poster 与 fanart。qBittorrent 保存根目录和 FeedDock 本地挂载目录可以不同，但必须映射到同一个宿主机目录，例如 qBittorrent 使用 /vol2/1000/影视，FeedDock 使用 /media。启用 bangumi.ini 后还会写入 Bangumi ID。

RSS 设置

控制 RSS 读取、超时、自动跳过和完结停用；下载完成状态每 2 分钟检查一次。

此选项必须为全部启用订阅开启“自动重命名”。下载工具与 FeedDock Docker 必须访问同一宿主机目录；容器内路径不同会按下载根目录与本地挂载根目录自动映射。

详细说明

FeedDock 只检查计算出的目标季度目录，并按规范文件名进行完整匹配，不递归扫描整个媒体库。启用后，新增、编辑、导入或批量启用关闭了自动重命名的订阅都会被后端拒绝。
